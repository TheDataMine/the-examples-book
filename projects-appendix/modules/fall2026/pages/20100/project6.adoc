=== Question 1

The Segment Anything Model (SAM) is a AI foundational model that is designed for image segmentation. This model is able to identify and isolate any object within an image or video with zero-shot generalization. 

We want to introduce you to SAM and to masks, and use it to further our work on the image processing.

Read our notes about SAM here:

https://the-examples-book.com/projects/fall2026/20100/introductiontosam

1.1 Explain (in 1 to 2 sentences) what SAM is, and what it is used for in image processing

1.2 Define and predict masks for each object in the shopping mall image, using SAM

1.3 Assign, resize, and overlay the mask for *one* object on the original image.

=== Question 2

Now that we know how to make masks, we want to make the masks systematically:  https://the-examples-book.com/projects/fall2026/20100/systematicmasks

2.1 Use Method 1 to display an image for each object mask in the shopping mall image. Display the result.

=== Question 3

=== Question 4

We can also remove objects from an image, either one object at a time:

https://the-examples-book.com/projects/fall2026/20100/removingoneobject

https://the-examples-book.com/projects/fall2026/20100/removingmultipleobjects
